## 계산 방식 (원본 엑셀 수식 그대로)

- 해당원가 = 매입원가(kg) × 중량(kg) + 포장비(케이스 500 · 박스 1000 · 팩 500 · 없음 0)
- 납품가 = `ROUNDUP(해당원가 × 이율, -1)` (원본에서 -2·0.78 역산 등 예외도 그대로 보존)
- 농협판매가 = `ROUNDUP(납품가 ÷ 0.77, -1)` (0.82·-3 자리 예외 보존)
- 광양동부농협 = `ROUND(납품가 ÷ 0.83, -1)` / 파머스·동부슈퍼 = `ROUND(납품가 × 수수료 ÷ 0.84, -2)`
- 중량에 따라 이율이 자동인 품목(1kg↑1.30 · 0.5↑1.40 · 0.3↑1.45 · 0.1↑1.50 · 그 외 1.60)도 그대로 동작합니다.
- 하나로마트: 용량단가 → 소분비(5%, 1.5kg은 0) → 완제품단가 → `ROUNDUP(×(1+자사이윤),-2)` → `ROUNDUP(÷(1-업체이윤),-2)`

## 보안

- 실제 품명·바코드·매입원가·거래처 단가는 저장소에 **평문으로 올리지 않습니다.** 모든 자료는 `data.enc.json` 하나에 **AES-256-GCM + PBKDF2-SHA256(310,000회)** 로 잠겨 있습니다.
- 앱을 처음 열 때 **단가표 비밀번호**를 한 번 넣으면, 그 기기에서는 열쇠를 IndexedDB에 보관해 다음부터는 묻지 않습니다(포털에서 들어와도 바로 열립니다).
- 화면에서 바꾼 내용은 그 열쇠로 다시 잠가 `localStorage`에 저장합니다.
- 로그인 화면에는 어떤 비밀번호 힌트도 두지 않았습니다.
- 비밀번호를 잊었을 때는 잠금 화면의 **엑셀 단가표로 새로 시작**으로 원본 엑셀을 올려 쓸 수 있습니다.

## 단가 자료 갱신

1. **전체품목 → 엑셀 단가표 올리기**(또는 설정 → 새 단가표 엑셀 올리기)로 새 `상품장_전체_2026.xlsx`를 올립니다. (`품명`·`매입원가`·`중량`·`포장`·`이율` 열을 자동으로 찾습니다)
2. 설정 → **🔐 암호화 파일 만들기**로 `data.enc.json`을 내려받아 이 폴더에 덮어 올리면 모든 기기에 같은 단가가 열립니다.
