# 📦 택배주소출력 (parcel-label)

경덕농수산 거래처의 **택배주소를 A4 가로 한 장에 크게 인쇄**하는 웹앱입니다.
통합포털(`https://hanseong1007.github.io/`)의 네 번째 메뉴로 들어갑니다.

- 주소: <https://hanseong1007.github.io/parcel-label/>
- 로그인: 통합포털과 같은 아이디·비밀번호 (구글 시트 `계정목록`의 공용 계정)
- 거래처 원본: 구글 시트 「경덕농수산 택배주소출력 거래처」의 `거래처목록` 탭 (2,454건)

## 화면

| 왼쪽 | 오른쪽 |
| --- | --- |
| 거래처 목록 + 검색(고객명·전화·휴대폰·주소·사업장주소·코드) | 택배주소 미리보기(A4 가로 1장) |

1. 목록에서 거래처를 누르면 주소·상호·연락처가 미리보기에 채워집니다.
2. **연락처**는 `휴대폰 / 전화번호 / 직접` 중 하나만 인쇄됩니다(값이 있는 쪽 자동 선택).
3. **주소**는 `주소 / 사업장주소 / 직접` 중 하나만 인쇄됩니다.
4. **보내는 품목**을 입력하고 오른쪽 `<<착불>> · <<선불>> · 표기 없음 · 직접 입력`을 고릅니다.
5. `🖨 인쇄 / PDF 저장` → A4 가로 한 장에 네 줄(주소 / 상호 / 연락처 / 품목+운임)만 인쇄됩니다.
   긴 주소·상호도 한 장을 넘지 않게 글자 크기가 자동으로 줄어듭니다.
   글꼴·항목별 크기·굵기는 **🔤 서식 조절**에서 바꿀 수 있습니다(아래).
6. `➕ 거래처`로 새 거래처를 추가하고, 목록에서 고른 뒤 `✏️ 거래처 수정`으로 고칠 수 있습니다.
   삭제는 관리자만 됩니다. 모든 변경은 구글 시트에 바로 저장됩니다.

## 서식 조절 (글꼴 · 크기 · 굵기)

오른쪽 패널의 **🔤 서식 조절**을 눌러 펼치면 미리보기와 인쇄물의 글씨를 그 자리에서 바꿀 수 있습니다.

| 조절 | 방법 |
| --- | --- |
| 글꼴 | `고딕(기본)` · `나눔고딕` · `나눔명조(바탕체)` · `검은고딕` · `도현체` 중 선택 |
| 항목별 크기 | `주소` · `거래처명` · `연락처` · `품목` 마다 `−` / `+` (기본 100%, 60~160%, 10%씩) |
| 항목별 굵기 | `진하게` 체크 (끄면 보통 굵기) |
| 되돌리기 | `서식 초기화` |

- 100%는 **그 줄의 폭을 가득 채우는 크기**입니다. 그보다 긴 글씨는 한 줄을 넘지 않게 그 안에서 자동으로 줄어듭니다.
- 네 줄을 모두 키워 A4 한 장 높이를 넘길 때만 전체를 같은 비율로 줄여 한 장에 담습니다.
- 설정은 이 기기 `localStorage`(`pl.fmt.v1`)에만 저장됩니다. 고객 이름·전화·주소는 들어가지 않습니다.
- 글꼴 파일은 Google Fonts 에서 받아오며, 인터넷이 없거나 늦으면 맑은 고딕 등 시스템 글꼴로 인쇄됩니다.

## 개인정보 보호

- 이 폴더의 어떤 파일에도 **고객 이름·전화번호·주소가 들어 있지 않습니다.** 화면은 로그인 뒤
  구글 시트(Apps Script)에서 받아 옵니다.
- 받아 온 목록은 이 기기 `localStorage`에 **SHA-256 카운터 암호문**(사용자별 열쇠로 감싼 32자리 키)으로만
  저장됩니다. 로그아웃하면 열쇠가 사라져 암호문을 풀 수 없습니다.
- 시트 통신은 **비밀번호를 확인해 발급한 토큰**이 있어야만 응답합니다(토큰 없이 `list` 호출 시 거부).
- `noindex` — 검색엔진에 노출되지 않습니다.

## 시트 API (Apps Script)

배포: `경덕농수산 택배주소출력 시트` 프로젝트의 웹 앱(실행: 나, 액세스: 모든 사용자).
`action` 하나로 동작합니다. (`POST`는 본문 JSON, `GET`은 쿼리 모두 지원)

| action | 보내는 값 | 하는 일 |
| --- | --- | --- |
| `ping` | – | 시트 이름·전체 건수 |
| `login` | `id`, `pw` | 공용 계정 시트에서 비밀번호 확인 → 180일 토큰 |
| `list` | `id`, `token`, `page`, `size` | 거래처 목록(기본 900건씩, 3페이지) |
| `save` | `id`, `token`, `row{code,name,tel,mobile,addr,biz}` | 추가/수정(코드 없으면 자동 부여) |
| `del` | `id`, `token`, `code` | 삭제 |

`거래처목록` 탭의 열 순서: `코드 | 고객명 | 전화번호 | 휴대폰 | 주소 | 사업장주소`.

## 배포

```bash
cp documents/portal/parcel-label/index.html deploy/portal-repo/parcel-label/index.html
cd deploy/portal-repo && git add -A && git commit -m "택배주소출력: 거래처 목록·A4 인쇄·시트 연동" && git push origin main
```

포털(`documents/portal/index.html`)에는 `parcel` 메뉴가 등록돼 있고, `admin`·박한성 계정은 자동으로
전체 메뉴를 봅니다. 다른 직원은 포털 `사용자 관리`의 `택배주소출력` 체크박스로 부여합니다.
