# 경덕농수산 · 쿠팡택배 (`/coupang-order/`)

쿠팡윙 주문 → 발주확인 → 롯데택배(ALPS) 접수 → 운송장 등록을 한 화면에서 처리하는 웹앱입니다.
경덕농수산 통합포털의 **다섯 번째 메뉴 「쿠팡택배」**이며, 포털 로그인(SSO)을 그대로 이어받습니다.

- 배포 주소: `https://hanseong1007.github.io/coupang-order/`
- 폴더: 통합포털 저장소(`hanseong1007/hanseong1007.github.io`)의 `coupang-order/`
- 파일: `index.html`(화면 한 장) · `xlsx.full.min.js`(SheetJS 0.20.3, 엑셀 읽기/쓰기)

## 4단계 흐름 (실제 쿠팡윙·ALPS 화면 기준)

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 현황판 | 상단 | 쿠팡윙 배송관리와 같은 9칸 — 출고중지요청 · 당일출고필요 · 출고지연 · 장기미배송 / 결제완료 · 상품준비중 · 배송지시 · 배송중 · 배송완료. 칸을 누르면 그 상태만 걸러 봅니다. |
| 1. 쿠팡윙 확인·발주확인 | 왼쪽: 쿠팡윙 배송관리 바로가기 + 주문 엑셀 올리기(끌어다 놓기) + 샘플 12건 + 예시 양식 / 오른쪽: 불러온 주문 표, 상태 필터, 발주확인 체크·일괄 처리 | `.xlsx/.xls/.csv`를 읽어 열 이름을 자동으로 맞춥니다. 실제 쿠팡윙 **`DeliveryList` 41열**(`Delivery` 시트)을 그대로 읽습니다 — `주문번호`·`묶음배송번호`·`택배사`·`운송장번호`·`주문시 출고예정일`(또는 `분리배송 출고예정일`)·`주문일`·`노출상품명(옵션명)`·`구매수(수량)`·`수취인이름`·`수취인전화번호`·`우편번호`·`수취인 주소`·`배송메세지`·`출고일(발송일)`·`배송완료일`·`구매확정일자`. 출고예정일이 오늘이면 `당일출고필요`, 지났으면 `출고지연`으로 잡습니다. |
| 2. 당일 출고 선택 | 오늘 보낼 주문만 체크(발주확인 안 된 결제완료 건은 잠김) | 체크한 건만 3단계로 넘어갑니다. |
| 3. ALPS 접수·송장 | ALPS 바로가기 + **일괄주문접수용 엑셀 내려받기**(수하인명·전화번호·휴대폰·우편번호·주소·품목명·수량·배송메시지) + 건별 정보 복사 + **100mm 감열지 / A4 송장 미리보기·인쇄** | 엑셀은 ALPS `접수 → 일괄주문접수` 업로드에 그대로 쓰고, 한 건만 접수할 때는 `정보 복사`로 칸별 값을 붙여넣습니다. |
| 4. 운송장 등록 | ALPS 결과 엑셀 올리기 / 번호 붙여넣기 / 줄마다 직접 입력 + **쿠팡윙 운송장 일괄등록용 엑셀**(주문번호·택배사·운송장번호) + **원본 주문서에 운송장 채우기**(1단계에서 올린 `DeliveryList` 41열을 그대로 두고 `운송장번호` 칸만 채워 내려받기) + 건별 복사 + 송장 인쇄 | 결과 엑셀은 운송장번호 열과 주문번호(또는 수령인)를 찾아 매칭합니다. 이름이 맞지 않는 줄은 **추측해서 넣지 않고** 미매칭으로 알려 줍니다. |

## 안전·보안

- 고객 주문·주소는 **브라우저 안에서만** 다룹니다. 서버도 GitHub도 거치지 않습니다.
- 화면에서 불러온 주문은 탭을 닫으면 사라지고, 새로고침으로 이어받을 때는 로그인 계정에서 만든 열쇠로 **암호문**만 `sessionStorage`에 둡니다(다른 기기·다른 계정에서는 열리지 않음).
- 1단계에서 올린 **원본 주문서(41열)**는 4단계의 `운송장 채우기`를 위해 메모리에만 두고 저장하지 않습니다(새로고침하면 사라짐).
- 검증용 테스트 자료는 **가상의 이름·주소**(`테스트하나`, `가상로`)로만 만들고, 실제 쿠팡윙 엑셀의 고객 정보는 코드·테스트·스크린샷·저장소 어디에도 넣지 않습니다.
- 쿠팡윙/ALPS **아이디·비밀번호는 저장하지 않습니다**. 로그인은 통합포털 계정 하나로 합니다.
- 자동 로그인·자동 발주확인·자동 접수는 하지 않습니다. 실제 클릭은 각 사이트에서 사람이 합니다.

## 로그인 (통합포털 SSO)

- 포털에서 로그인한 상태면 `kd.portal.sso.v1` 세션을 그대로 이어받아 바로 열립니다.
- 포털 세션이 없으면 잠금 화면이 뜨고, ①같은 아이디·비밀번호로 로그인하거나 ②`통합포털에서 로그인`으로 이동합니다(계정은 포털 계정 목록·구글 시트 `users_get` 기준).
- 로그아웃하면 포털 SSO까지 함께 풀립니다(포털과 같은 규칙).

## 상태 계산 (배송상태 열이 없을 때)

쿠팡윙 `DeliveryList`에는 `배송상태` 텍스트 열이 따로 없습니다. 그래서 주문서를 읽을 때 아래 순서로 상태를 만듭니다.

1. `배송완료일`이 있으면 → `배송완료`
2. `운송장번호`가 있으면 → `배송중`
3. 그 외 → `상품준비중`(발주확인 후 내려받은 파일 기준). 여기에 `주문시 출고예정일`이 **오늘이면 `당일출고필요`**, **오늘 이전이면 `출고지연`**으로 현황판에 잡힙니다.
4. 4단계에서 운송장번호를 넣어도 그 건은 `배송중`으로 옮겨 갑니다.
