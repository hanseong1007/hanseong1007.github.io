# 🗒️ 생산일지 (경덕농수산)

종이 생산일지(1번 사진)와 같은 모양으로 날짜별 생산 기록을 적고, **담당자 → 부장 → 대표이사** 전자결재를 거쳐
A4 세로로 인쇄하는 앱입니다. 품목의 원산지·유통기한은 **원물 정보 앱에서 자동으로** 가져옵니다.

- 주소: <https://hanseong1007.github.io/production-log/>
- 통합포털 9번째 메뉴 `🗒️ 생산일지` 로 들어갑니다(포털 한 번 로그인으로 바로 열림).

## 쓰는 순서

1. **＋ 생산일지 쓰기** → 날짜(기본 오늘)와 작성자가 채워집니다.
2. **＋ 품목 추가** → 세 가지 방법 중 하나로 품목을 넣습니다.
   - **🔍 검색**: 원물 정보 목록에서 이름·별칭·바코드·초성(예: `ㅈㅊㅍ`)으로 찾기
   - **📷 바코드**: 카메라로 바코드 스캔(`BarcodeDetector`, 지원 안 되면 숫자 직접 입력)으로 바로 찾기
   - **📸 사진**: 라벨·제품 사진을 찍어 판별(AI 키가 있으면 자동 판별, 없으면 이름이 비슷한 후보 제시)
3. 품목을 고르면 **원산지·유통기한이 원물 정보의 최신 값으로 자동 입력**됩니다(작업시간은 앞 줄 값을 이어받음). 칸에서 직접 고칠 수도 있습니다.
4. 수량을 적고 **임시저장** 또는 **상신**.
5. **결재함**에서 부장·대표가 승인/반려합니다(권한은 포털 사용자 관리의 결재 권한을 그대로 씀).
6. 승인된 일지는 **인쇄**로 종이 양식 그대로 A4 출력합니다.

## 화면

| 화면 | 내용 |
|---|---|
| 목록 | 기간(기본 이번 달)·상태로 걸러 보기. 담당자는 자기 일지만, 부장·대표·관리자는 전체를 봅니다. 상태 배지 `작성중 · 부장 결재 대기 · 대표 결재 대기 · 승인완료 · 반려` |
| 작성 | 결재란(담당자·부장·대표이사)에 지금 상태와 결재자·시각이 표시됩니다. 표는 `NO · 제품명 · 원산지 · 유통기한 · 작업시간 · 중량 · 수량` |
| 결재함 | 내 차례인 문서 수를 빨간 배지로. 승인/반려 의견을 남길 수 있습니다. |
| 인쇄 | `생 산 일 지` 제목, 오른쪽 결재란(담당자·부장·대표이사 결재자·날짜), 날짜 줄, 30행 표, 아래 `경덕농수산` — 종이 양식과 같습니다. |

## 전자결재 흐름

- **상신** → 담당자 칸에 작성자·시각이 찍히고 `부장 결재 대기`
- **부장 승인** → `대표 결재 대기` / **반려** → `반려`(작성자가 고쳐 다시 상신)
- **대표 승인** → `승인완료` / **반려** → `반려`
- 권한: 포털 `사용자 관리`의 결재 권한 `본부장`·`대표`·`전체`(관리자)를 그대로 씁니다. 본부장 계정은 생산일지에서 **부장** 칸을 결재합니다.
- 상신한 작성자는 부장 결재 전까지 **상신 취소**할 수 있습니다.

## 다른 기기와 자동 맞춤 (구글 시트 · 암호화)

원물정보 앱과 **같은 시트·같은 자료 비밀번호**를 씁니다. 일지·결재 상태는 암호화해 시트에 오가고,
부장·대표가 다른 기기에서 결재해도 45초 안에(또는 다시 열 때) 상태가 맞춰집니다.
