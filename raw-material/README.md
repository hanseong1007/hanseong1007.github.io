# 🏷️ 원물 정보 (경덕농수산)

품목(원물)의 **원산지·유통기한·표시사항(한글표시사항 라벨)** 을 한곳에 모아 두는 앱입니다.
생산일지 앱과 **같은 자료**를 쓰며, 생산일지에서 품목을 고르면 여기 있는 **최신 원산지·유통기한**이 자동으로 들어갑니다.

- 주소: <https://hanseong1007.github.io/raw-material/>
- 통합포털 8번째 메뉴 `🏷️ 원물정보` 로 들어갑니다(포털 한 번 로그인으로 바로 열림).

## 화면

| 화면 | 하는 일 |
|---|---|
| **목록** | 품목명·별칭·바코드·제조원·품목보고번호를 **글자·초성**(예: `ㅈㅊㅍ`)으로 검색. **분류**(건어물·수산물·해조류·견과류·농산물·공산품·기타)와 **소비기한**(있음·30일 내·없음)으로 걸러 보고, 이름순·소비기한 빠른순·최근 수정순으로 정렬합니다. 유통기한 남은 날짜(30일 이내 경고·기한 지남 빨강)를 배지로 보여 줍니다. |
| **상세** | 입력한 모든 항목과 사진(눌러서 크게 보기), 영양정보 요약. **표시사항 라벨**(3번 사진과 같은 한글표시사항), **표시사항 전체 복사**, **라벨 인쇄**. |
| **편집** | 아래 항목 전부. 제조년월일 + `제조일로부터 N년/개월/일` 을 넣으면 유통기한 날짜를 **자동 계산**합니다(직접 날짜로도 입력 가능). |
| **사진** | 박스 라벨·원물 사진을 여러 장 담고 대표 사진을 지정. 담을 때 이 기기에서 줄여(긴 변 1,400px) **암호화해** 저장·전송합니다. |
| **AI 라벨 읽기** | 설정에 Gemini API 키를 넣으면 라벨 사진에서 글자를 읽어 폼을 자동으로 채웁니다(키가 없어도 수동 입력은 그대로 동작). |

## 입력 항목 (박스 라벨 그대로)

- **기본**: 품목명, 별칭·검색어, 바코드, 품목보고번호, 류별(식품유형), 원료·원산지
- **원료·표시 문구**: 원료명 및 함량, 알레르기 유발물질, 보관방법, 반품·교환 안내, 부정·불량식품 신고 안내
- **제조원**: 업소명, 소재지, TEL, FAX, 제조가공지
- **규격·기한**: 분류, 중량(내용량), 제조년월일, 유통기한(제조일로부터 N / **날짜 직접**), **규격별 소비기한**(한 줄에 `2L 2028-04-28` 처럼)
- **영양정보**: 총내용량, 기준(예: `100g당`), 열량, 나트륨·탄수화물·당류·지방·트랜스지방·포화지방·콜레스테롤·단백질의 **값과 1일 기준치 %**, 안내 문구
- 메모

## 처음 넣어 둔 원물 (2026-11-27)

- **상품관리장(`상품장_전체_2026.xlsx`) 경덕 시트의 품명**에서 중량·규격을 뗀 원물 **479개**를 넣었습니다. 원산지·규격·바코드는 상품관리장 값을 그대로 옮겼습니다.
- **현장 소비기한 일람표 사진**(2026-11-27, 손글씨)에서 읽은 소비기한을 이름에 맞춰 **80개**에 채웠습니다(기존 7개 포함). 사진에만 있고 상품관리장에 없는 이름(아몬드·땅콩·진미채 등)은 현장에서 부르는 이름 그대로 따로 넣었습니다.
- 규격마다 소비기한이 다른 원물(쥐치포 M·2L·3L, 호두 ½·¼)은 대표 날짜를 유통기한에, 규격별 날짜를 `규격별 소비기한`에 함께 적어 두었습니다.
- 다시 넣거나 더할 때: `python3 scripts/raw_material_seed.py` → `python3 scripts/raw_material_merge.py` (이미 있는 이름은 건너뜁니다)

## 다른 기기와 자동 맞춤 (구글 시트 · 암호화)

품목·사진·수정 시각을 이 기기에서 **AES-256-GCM**(PBKDF2-SHA256 310,000회)으로 잠가 두고,
바뀐 부분만 구글 시트에 올립니다. 시트에는 **암호문만** 있고 품목명·원산지·유통기한·사진은 평문으로 없습니다.

## 통합포털 1회 로그인

1. 포털 로그인 때 포털이 **로그인 비밀번호에서 만든 열쇠**(`kdw-portal-kek`, IndexedDB)를 이 기기에 둡니다.
2. 원물정보 앱은 그 열쇠로 **자료 비밀번호 감싸개**를 풀어 자료를 열므로, 비밀번호를 묻지 않습니다.
3. 처음 시작한 기기에서 설정 → **자료 비밀번호 보기**로 그 값을 볼 수 있습니다. 다른 포털 계정·새 기기에서는 처음 한 번 그 비밀번호를 넣으면 됩니다.
4. 포털에서 로그아웃하면 이 기기의 열쇠도 지워집니다.
