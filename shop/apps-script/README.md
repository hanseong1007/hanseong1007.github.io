# 쇼핑몰 동기화 — Google Apps Script 배포 절차

`shop-sync.gs` 는 쇼핑몰의 **회원 · 거래처 · 주문**을 구글 시트에 저장해 여러 기기에서 같이 쓰게 하는 웹앱입니다.
비밀번호는 **salt + SHA-256 해시**만 저장하며, 전체 목록은 **관리자 키**가 있어야만 열립니다.

## 1. 준비

1. Google 계정(`phs76041@gmail.com`)으로 새 스프레드시트를 만듭니다. 이름 예: `바다로운 쇼핑몰 운영`.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고 `shop-sync.gs` 전체를 붙여넣습니다.
4. 맨 위 `ADMIN_KEY` 를 길고 무작위한 값으로 바꿉니다. 예:
   ```js
   var ADMIN_KEY = 'bd-8f3c1a7e92d44b0e9c6f5a1d3e7b2c90';
   ```
   - 이 값은 **사이트 코드나 GitHub에 올리지 않습니다.**
   - 쇼핑몰 관리자 화면에서 한 번 입력하면 그 기기 브라우저에만 저장됩니다.
5. 저장(Ctrl+S).

## 2. 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. 유형 **웹 앱**.
3. 설정
   - 설명: `바다로운 쇼핑몰 동기화 v1`
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자(익명 포함)**
4. **배포** → 권한 승인(처음 한 번).
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 3. 쇼핑몰에 연결

1. `documents/shop/products.json` 의 `store.syncUrl` 에 복사한 주소를 넣습니다.
   ```json
   "syncUrl": "https://script.google.com/macros/s/…/exec"
   ```
2. 쇼핑몰을 다시 배포합니다.
3. 관리자(통합포털 admin)로 쇼핑몰에 들어가 **내 정보 → 거래처·회원 관리** 를 엽니다.
4. 위쪽 노란 **관리자 키** 칸에 2-4의 `ADMIN_KEY` 를 넣고 **저장**.
5. `☁️ 시트와 동기화됨` 이 보이면 연결 완료입니다. `시트 동기화` 버튼으로 수동 동기화할 수 있습니다.

## 4. 시트에 생기는 탭

| 탭 | 내용 |
|---|---|
| `members` | 아이디(이메일), 이름, 연락처, 우편번호·주소, salt, hash, 반복 횟수, 권한, 상태, 가입일 |
| `dealers` | 사업자등록번호, 로그인 아이디, 거래처명, salt, hash, 등급, 할인, 상태 |
| `orders` | 주문번호, 일시, 회원 아이디, 주문자·연락처·이메일, 상품 JSON, 금액, 결제, 상태, 배송지 JSON |

- 행이 자동으로 쌓이고, 같은 아이디/주문번호는 최신 값으로 갱신됩니다.
- `active=false` 는 비활성, `deleted=true` 는 삭제(로그인 불가)입니다.
- `hash` 는 되돌릴 수 없는 해시입니다. 원래 비밀번호는 시트에 없습니다.

## 5. 확인

```bash
curl -sL '<웹앱 URL>?action=shop_get&key=<ADMIN_KEY>' | head -c 300
```

- 키가 맞으면 `{"ok":true,"shop":{...}}`
- 키가 틀리면 `{"ok":false,"error":"unauthorized"}`

## 6. 문제가 생기면

| 증상 | 확인 |
|---|---|
| `unauthorized` | 관리자 키가 `shop-sync.gs` 의 `ADMIN_KEY` 와 같은지 |
| `시트에 연결하지 못했습니다` | 배포 액세스가 **모든 사용자(익명 포함)** 인지, `/exec` 주소인지(`/dev` 아님) |
| 회원 로그인이 안 됨 | 시트 `members` 탭에 그 아이디가 있는지, `active` 가 `FALSE` 가 아닌지 |
| 거래처 로그인이 안 됨 | `dealers` 탭의 `loginId` 또는 사업자번호, `active` 상태 |
| 비밀번호를 잊음 | 관리자 화면 → 거래처 `비밀번호 변경` / 회원은 새로 가입하거나 관리자가 삭제 후 재가입 |

## 7. 보안 메모

- 웹앱은 익명 접근이 가능하지만, **전체 목록은 관리자 키 없이는 반환하지 않습니다.**
- 로그인은 아이디로 `salt` 만 조회한 뒤 브라우저가 해시를 만들어 보내고 서버가 비교합니다.
  비밀번호 평문은 네트워크로 나가지 않습니다.
- 관리자 키를 바꾸면 기존 기기의 저장된 키는 무효가 됩니다. 각 기기에서 새 키를 다시 입력하세요.
- 주문에는 고객 이름·연락처·주소가 들어가므로, 스프레드시트 공유 범위를 회사 관계자로 제한하세요.
