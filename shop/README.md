# 🛒 바다로운 쇼핑몰 (경덕농수산)

`(주)경덕농수산`의 온라인 쇼핑몰 **바다로운**입니다. 통합포털의 **6번째 메뉴 `🛒 바다로운 쇼핑몰`** 로 연결되며,
포털 SSO 없이 누구나 열리는 공개 페이지입니다.

| 구분 | 주소 / 파일 |
|---|---|
| 라이브 | https://hanseong1007.github.io/shop/ |
| 포털 카드 | https://hanseong1007.github.io/ → 🛒 바다로운 쇼핑몰 |
| 화면 | `documents/shop/index.html` (한 파일, 외부 라이브러리 없음) |
| 상품·가격 | `documents/shop/products.json` **← 가격은 이 파일 하나만 고치면 됩니다** |
| 상세페이지 문구 | `documents/shop/details.json` (상품별 히어로·Check Point·활용법·표기정보) |
| 상세페이지 이미지 | `documents/shop/images/detail/` (바베큐 오징어 실제 상세컷 13장 + 썸네일) |
| 동기화 서버 | `documents/shop/apps-script/shop-sync.gs` (Google Apps Script) |

## 1. 이번에 추가된 것

### ① 쿠팡형 상품 상세페이지
상품 카드의 **상세보기**를 누르면 전체 화면 상세페이지가 열립니다.

- **상단 구매 영역** — 상품 이미지·상품명·정가/할인가·도매가(거래처)·수량·장바구니/바로 주문
- **탭 3개** — `상품정보` / `상세정보` / `배송·교환`
- **상품정보 탭** — 필수 표기정보 표(제품명·식품유형·내용량·원산지·원재료명·보관방법·유통기한·제조원/판매원·소비자상담실 `061-743-1790`)
- **상세정보 탭** — ① 감성 히어로 배너 ② Check Point 3가지 ③ 추천 활용법 ④ 맛있게 먹는 팁 ⑤ 위생·포장·보관 ⑥ 브랜드 이야기
- **바베큐 오징어 500g · 1kg · 10kg · 모둠세트** — 기존에 만든 실제 쿠팡 상세페이지 이미지 13장(page-01~14)을 세로로 이어 붙여 진짜 쿠팡 상세페이지처럼 보입니다.
- 긴 상세페이지는 **`상세정보 펼쳐보기` / `상세정보 접기`** 로 접었다 펼 수 있습니다(내용이 짧은 상품은 버튼이 자동으로 숨겨집니다).
- 원산지가 확인되지 않은 상품은 계속 **`상품 표시사항 참조`** 로 표시합니다.

### ② 일반 회원가입 · 로그인
- 헤더의 **로그인** 버튼 → `로그인` / `회원가입` 탭
- 가입 항목: 이름, 연락처, 아이디(이메일), 비밀번호, 우편번호, 기본 배송지
- 가입·로그인하면 **주문서의 이름·연락처·배송지가 자동으로 채워집니다.**
- **내 정보**에서 배송지 수정, **내 주문내역** 확인, 로그아웃
- 비밀번호는 **salt + SHA-256(1,024회 반복)** 해시로만 저장합니다. 평문은 저장·전송하지 않습니다.
- 로그인 화면에 어떤 초기 비밀번호 힌트도 표시하지 않습니다.

### ③ 관리자 — 📦 상품 관리 (가격·원산지·재고·소비기한)
관리자 화면에 **📦 상품 관리** 탭이 추가되었습니다. 상품마다 아래 값을 그 자리에서 고치면
**수정 즉시 구글 시트(`products` 탭)에 저장**되고, PC·스마트폰 어느 기기에서 쇼핑몰을 열어도 그 값으로 보입니다.

| 고칠 수 있는 값 | 쇼핑몰에 반영되는 곳 |
|---|---|
| 상품명·분류·규격·한 줄 설명·배지 | 상품 카드, 상세페이지, 카테고리 칩 |
| 소비자가·판매가·도매가·도매 최소수량 | 카드 가격, 상세 가격, 장바구니·주문서, 거래처 도매가 |
| **원산지** | 상세페이지 표기정보 표 |
| **재고수량** | 카드·상세의 "재고 N개", 주문 수량 제한, 0이면 자동 품절 |
| **소비기한** | 상세페이지 표기정보 표 (예: `2027-06-30`, `제조일로부터 12개월`) |
| **보관방법** | 상세페이지 표기정보 표·보관 안내 |
| 품절 여부 | 카드·상세의 품절 표시, 주문 버튼 잠금 |
| 이미지 경로 / 새 사진 | 카드·상세 이미지 |

- **+ 새 상품 추가** — 초보자용 등록 화면이 열립니다.
  - **🔁 기존 상품 정보 불러오기**: 비슷한 상품을 고르면 분류·원산지·보관방법·할인 구조가 자동으로 채워집니다.
    상품명·규격·사진만 바꾸면 10초 만에 새 상품을 올릴 수 있습니다.
  - **📷 사진 선택**: PC·휴대폰 갤러리에서 사진을 고르면 브라우저가 가로 720px·WebP로 **자동 축소·압축**해
    미리보기로 보여 주고, 그대로 시트에 저장합니다(셀 한도 45,000자 이내로 자동 조정). 기존 이미지 선택도 가능합니다.
  - **📋 공통 안내 불러오기**: 배송·교환·판매자·보관 주의 문구를 한 번에 채웁니다.
- **⬇ 엑셀 내려받기 / ⬆ 엑셀 올리기**
  - 내려받기: 현재 상품 목록을 `바다로운_상품관리.xlsx`로 저장(입력안내 시트 포함).
  - 올리기: 고친 엑셀(.xlsx)·CSV를 올리면 **바뀐 내용을 미리 보여 주고**, 「적용하고 시트에 저장」을 누르면 일괄 반영합니다.
- **간편 수정**: 상품 행의 「간편 수정」을 누르면 같은 등록 화면이 값이 채워진 채로 열립니다.
- **주문이 들어오면 재고가 자동으로 줄고**, 0이 되면 품절로 바뀝니다(시트에서도 차감).
- 재고수량을 **비우면** 재고 표시·수량 제한 없이 판매합니다.

### ④ 관리자 — 🏪 공통 안내 (모든 상품 상세페이지 공통 문구)
- **배송·출고 안내 / 교환·반품 규정 / 고객센터·판매자 정보 / 기본 보관·섭취 주의사항**을 한 번만 적어 두면
  **모든 상품 상세페이지의 「배송·교환」 탭과 공통 안내**에 그대로 들어갑니다.
- 저장하면 구글 시트 `settings` 탭에 보관되어 모든 기기에 반영되고, 새로 올린 상품에도 자동 적용됩니다.
- 「라벨: 내용」 형태로 쓴 줄은 라벨이 굵게 표시됩니다.

### ⑤ 관리자 — 거래처·회원 관리
- **통합포털 관리자로 로그인한 기기**에서는 자동으로 관리자로 인식됩니다(`kd.portal.sso.v1`).
  쇼핑몰 자체 관리자 계정으로 로그인한 경우에도 열립니다.
- 관리자 화면에서 할 수 있는 일
  - **거래처 추가** — 거래처명·사업자등록번호·로그인 아이디·비밀번호·도매 등급(A/B/C)·추가 할인(%)
  - **비밀번호 변경** / **활성·비활성** / **삭제**
  - **일반 회원을 거래처로 승격** (회원 목록 → `거래처로 승격` → 사업자번호·비밀번호 입력)
  - 회원 **활성·비활성 / 삭제**
  - **주문 목록** 확인 (주문번호·주문자·상품·금액·결제수단·상태)
- 새로 만든 거래처는 상단 **거래처 도매**에서 `아이디(또는 사업자번호) + 비밀번호`로 로그인하면 도매가와 최소 주문 수량이 보입니다.
  등급 할인은 도매가에서 % 만큼 자동 계산됩니다.

## 2. 기기 간 동기화 (Google 시트 + Apps Script) — **연결 완료**

회원·거래처·주문을 여러 기기에서 같이 쓰려면 `apps-script/shop-sync.gs` 를 배포해 연결합니다.
**연결하지 않아도 쇼핑몰은 이 기기에 저장하며 정상 동작합니다.**

| 항목 | 값 |
|---|---|
| 시트 | `바다로운 쇼핑몰 운영` — https://docs.google.com/spreadsheets/d/1yfi9ZTpDCUVVfanVcsi-9ipycnLjc5gIhpCIzhe7OlE/edit |
| 웹 앱(`store.syncUrl`) | `https://script.google.com/macros/s/AKfycbw_XDZTeGEg-Dy3QKYirB62iC-NWsi3M4j5ihwMhzk563D7JsBn6XR1gfgWhvj8SWNiyA/exec` |
| 실행 계정 / 액세스 | `phs76041@gmail.com` / 모든 사용자(익명 포함) |

위 상태로 이미 배포되어 있으므로, **관리자 화면에서 관리자 키만 한 번 입력하면** 기기 간 동기화가 켜집니다.
관리자 키는 `shop-sync.gs` 의 `ADMIN_KEY` 와 같은 값이며 **사이트·GitHub에 올리지 않습니다**.

### 처음부터 다시 배포할 때

1. 쇼핑몰 운영용 Google 스프레드시트를 만들고 **확장 프로그램 → Apps Script** 를 엽니다.
2. `apps-script/shop-sync.gs` 내용을 붙여넣고, 맨 위 `ADMIN_KEY` 를 **길고 무작위한 값**으로 바꿉니다.
   (이 키는 사이트 코드에 넣지 않습니다.)
3. **배포 → 새 배포 → 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자(익명 포함)**
4. 배포 후 나오는 `https://script.google.com/macros/s/…/exec` 주소를
   `products.json` 의 `store.syncUrl` 에 넣고 쇼핑몰을 다시 배포합니다.
5. 쇼핑몰 **거래처·회원 관리** 화면 위의 **관리자 키** 칸에 2번의 `ADMIN_KEY` 를 한 번 입력합니다.
   (키는 그 기기 브라우저에만 저장됩니다.)

### 시트 구조
- `members` — 아이디, 이름, 연락처, 주소, salt, hash, 반복 횟수, 권한, 상태, 가입일
- `dealers` — 사업자등록번호, 로그인 아이디, 거래처명, salt, hash, 등급, 할인, 상태
- `orders` — 주문번호, 일시, 회원 아이디, 주문자, 연락처, 상품 JSON, 금액, 결제, 상태, 배송지 JSON
- `products` — 상품ID, 상품명, 분류, 규격, 설명, 소비자가, 판매가, 도매가, 도매 최소수량,
  원산지, 재고수량, 소비기한, 보관방법, 품절, 배지, 이미지, 정렬, 수정시각
- `settings` — 공통 안내 키/값 (shipping·returns·seller·care)

### 상품 API (관리자 키 없이 읽기 / 키 있어야 쓰기)
| action | 설명 |
|---|---|
| `shop_products_get` | 상품 목록 — 쇼핑몰 화면이 접속할 때마다 부른다(공개) |
| `shop_products_save` | 상품 저장·삭제 — `key` 필요 |
| `shop_settings_get` | 공통 안내 읽기(공개) |
| `shop_settings_save` | 공통 안내 저장 — `key` 필요 |
| `shop_order` | 주문 저장 + 주문 수량만큼 재고 자동 차감(응답의 `stocks`) |

### 안전 장치
- **전체 회원·주문 목록**(`shop_get`/`shop_save`)은 **관리자 키가 있어야만** 열립니다. 공개 주소만으로 고객 개인정보를 받아갈 수 없습니다.
- 로그인은 **아이디 → salt만** 받아 브라우저에서 해시를 만들고, 서버는 **해시만 비교**합니다.
- 회원가입은 서버에 **salt + 해시**만 올립니다. 평문 비밀번호는 어느 단계에서도 전송·저장하지 않습니다.
- 주문 저장 시 회원 아이디·해시가 맞을 때만 회원 주문으로 기록합니다.
- Apps Script 는 `LockService` 로 동시 저장을 한 줄로 세웁니다.
- 관리자 키를 잊으면 Apps Script 의 `ADMIN_KEY` 를 바꾸고, 각 기기의 관리자 화면에서 새 키를 다시 입력하면 됩니다.

> ✅ 위 시트·웹 앱으로 실제 동기화까지 검증했습니다. 쇼핑몰 화면에서 서로 다른 브라우저 4개(기기 A~D)로
> 회원가입 → 다른 기기 로그인 → 주문 → 관리자 거래처 추가·비밀번호 변경·회원 승격 → 새 기기 거래처 도매가 →
> 또 다른 기기의 주문내역까지 확인했고(`scripts/test_shop_sync_e2e.py`), 끝난 뒤 테스트 데이터는 지웠습니다.
> 네트워크 없이 같은 프로토콜만 확인할 때는 `scripts/test_shop_members.py`(모의 시트)를 씁니다.

## 3. 상품·가격 바꾸는 방법

`products.json` 을 열어 상품 항목을 고치고 저장한 뒤 배포하면, 새로고침 즉시 화면 전체에 반영됩니다.
(브라우저가 예전 파일을 물고 있지 않도록 `cache: 'no-cache'`로 불러옵니다.)

| 필드 | 뜻 | 비고 |
|---|---|---|
| `id` | 상품 고유 키 | `details.json` 의 키와 같아야 상세 문구가 붙습니다 |
| `name` / `category` / `weight` | 상품명·분류·규격 | |
| `retailPrice` / `salePrice` | 정가·할인가 | 할인율 자동 계산 |
| `wholesalePrice` / `wholesaleMinQty` | 거래처 도매가·최소 수량 | 등급 할인은 도매가에서 % 계산 |
| `badge` / `inStock` / `image` | 배지·품절·이미지 | |
| `summary` / `origin` / `storage` | 한 줄 설명·원산지·보관 | 원산지는 실제 값으로 |

상품을 추가하면 `details.json` 에 같은 `id` 로 상세 문구를 넣어 주세요. 없으면 기본 상세가 나옵니다.
`scripts/shop_csv_to_json.py` 로 엑셀(CSV)에서 가격을 한 번에 바꿀 수 있습니다(상세 문구는 유지).

> 이제는 **관리자 화면 📦 상품 관리**에서 바꾸는 것이 기본입니다(시트에 저장 → 모든 기기 반영).
> `products.json` 은 시트에 아직 상품이 없을 때 쓰이는 기본값입니다.
> 시트를 처음 채우거나 `products.json` 을 크게 고친 뒤에는 `python3 scripts/shop_products_seed.py` 로 시트에 넣어 주세요.
> 엑셀 원본은 `python3 scripts/make_shop_product_xlsx.py` → `downloads/바다로운_상품관리.xlsx`.

## 4. 가게 정보·계좌·배송비

`products.json` 맨 위 `store` 블록에서 바꿉니다.

## 6. 오픈 전에 반드시 확인할 것

1. **가격은 전부 예시 값입니다.** 실제 판매가·도매가로 바꿔 주세요.
2. **입금 계좌는 예시(`000-0000-0000-00`)입니다.** 실제 계좌로 바꾸고 `bank.demo` 를 `false` 로.
3. **원산지·중량·유통기한 등 식품 표시사항**은 「식품 등의 표시·광고에 관한 법률」에 따라 실제 값이어야 합니다.
   확인되지 않은 상품은 `상품 표시사항 참조` 로 두었습니다.
4. **통신판매업 신고** 후 신고번호를 푸터에 넣어 주세요(현재 "신고 준비 중").
5. **카드 결제는 모의 승인**입니다. 실제 결제는 토스페이먼츠/포트원 계약 후 API 키를 연결해야 합니다.
6. **이용약관·개인정보처리방침**은 요약 초안입니다. 법률 검토가 필요합니다.
7. **도매가 가림은 화면 장치입니다.** 정적 사이트라 `products.json` 을 직접 열면 도매가가 보입니다.
8. **관리자 키**는 사이트 코드·`products.json` 에 넣지 마세요. Apps Script 안에만 두고, 관리자 화면에서 한 번 입력합니다.
9. 상품 이미지 중 바베큐 오징어 3컷과 상세페이지 13장은 실제 촬영·제작본이고, 나머지 7종은 SVG 일러스트입니다.
